
# Image Brightness Simulation

A beginner NumPy and Matplotlib project that simulates grayscale image processing.

## Features
- Create a 5×5 grayscale image
- Increase brightness
- Decrease brightness
- Flip horizontally
- Flip vertically
- Rotate the image by 90°
- Display results using Matplotlib

## Technologies
- Python
- NumPy
- Matplotlib
